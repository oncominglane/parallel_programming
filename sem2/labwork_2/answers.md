## Задание к допуску (вариант 1е, 2ж, 3з)

Ниже для каждого варианта указаны:

- вид цикла(ов) и область индексов;
- пары итераций-источник / итераций-приёмник;
- вектор расстояний **D** и вектор направлений **d**;
- тип зависимости;
- возможные варианты распараллеливания.

Обозначения:

- **K = (i₀, j₀)** — итерация-источник, в которой **записывается** элемент;
- **Λ = (i, j)** — итерация-приёмник, в которой тот же элемент **читается**;
- **D = Λ − K** — вектор расстояний;
- компоненты вектора направлений **d**:
  - `=` если Dₖ = 0,
  - `<` если Dₖ > 0,
  - `>` если Dₖ < 0.

---

### 1. Вариант 1е (MPI)

Фрагмент кода:

```c
for (i = 1; i < ISIZE; i++) {
    for (j = 8; j < JSIZE; j++) {
        a[i][j] = sin(5 * a[i-1][j-8]);
    }
}
```

**Область индексов:**

- i ∈ [1, ISIZE − 1],
- j ∈ [8, JSIZE − 1].


**Поиск зависимостей**

Итерация (i, j) записывает элемент `a[i][j]` и читает `a[i-1][j-8]`.

Для чтения элемента, ранее записанного этим же циклом, должны совпасть индексы:

- i₀ = i − 1  
- j₀ = j − 8  

Эти индексы попадают в область цикла, если:

- i ≥ 2,
- j ≥ 16.

Значит существует истинная зависимость:

- источник K = (i−1, j−8),
- приёмник Λ = (i, j).

**Вектор расстояний и направлений**

```
D = Λ − K = (1, 8)
d = (<, <)
```

**Тип зависимости**

- **Истинная (RAW)**: записали в (i−1, j−8), прочитали в (i, j).

**Возможные варианты распараллеливания (MPI)**

1. **Wavefront** (диагонали i + α·j = const).
2. **Разбиение по строкам + обмен граничной строки**:
   - каждый процесс получает свой диапазон i,
   - кроме процесса 0 все получают готовую «верхнюю» строку от предыдущего процесса,
   - порядок зависимости сохраняется.
3. Использование отдельного массива выходных данных (если задача это допускает).

### 2. Вариант 2ж (OpenMP)

Фрагмент:

```c
for (i = 0; i < ISIZE - 2; i++) {
    for (j = 3; j < JSIZE; j++) {
        a[i][j] = sin(0.1 * a[i+2][j-3]);
    }
}
```

**Область индексов:**

- i ∈ [0, ISIZE − 3],
- j ∈ [3, JSIZE − 1].

**Поиск зависимостей**

Итерация (i, j):

- записывает `a[i][j]`,
- читает `a[i+2][j-3]`.

Чтобы прочитать значение, записанное в этом же цикле:

- i₀ = i + 2  
- j₀ = j − 3  

Это означает:

- запись происходит позже, чем чтение → типичная **антизависимость (WAR)**.

**Вектор расстояний и направлений**

```
D = (2, -3)
d = (<, >)
```

**Тип зависимости**

- **Антизависимость (WAR)**: читаем старое значение, затем позже в другой итерации оно перезаписывается.

**Устранение зависимости**

Антизависимость снимается, если чтение производится не из того массива, куда происходит запись.

**Вариант распараллеливания:**

1. Создать копию входного массива:
   ```c
   for (i = 0; i < ISIZE; i++)
       for (j = 0; j < JSIZE; j++)
           a_old[i][j] = a[i][j];
   ```
2. Использовать:
   ```c
   #pragma omp parallel for collapse(2)
   for (i = 0; i < ISIZE - 2; i++) {
       for (j = 3; j < JSIZE; j++) {
           a[i][j] = sin(0.1 * a_old[i+2][j-3]);
       }
   }
   ```

Теперь зависимостей по данным между итерациями нет → цикл полностью параллелится.

### 3. Вариант 3з (OpenMP)

Код:

```c
// 1-й цикл
for (i = 0; i < ISIZE; i++) {
    for (j = 0; j < JSIZE; j++) {
        a[i][j] = sin(0.1 * a[i][j]);
    }
}

// 2-й цикл
for (i = 1; i < ISIZE; i++) {
    for (j = 0; j < JSIZE - 2; j++) {
        b[i][j] = a[i-1][j+2] * 1.5;
    }
}
```

---

#### 3.1. Первый цикл

- каждая итерация (i, j) читает и пишет **только** `a[i][j]`,
- между разными парами (i₁, j₁) и (i₂, j₂) нет общих данных.

**Вывод**

- зависимостей между итерациями нет,
- вектор направлений условно (`=`, `=`),
- можно распараллеливать:
  ```c
  #pragma omp parallel for collapse(2)
  ```

---

#### 3.2. Второй цикл

- читаем только `a` — массив, полностью вычисленный первым циклом,
- пишем только `b[i][j]`, без пересечений индексов.

**Вывод**

- зависимостей между итерациями нет,
- также полностью распараллеливается:
  ```c
  #pragma omp parallel for collapse(2)
  ```

---

### Итог по вариантам

- **1е (MPI)**  
  - Истинная зависимость RAW.  
  - D = (1, 8), d = (<, <).  
  - Требует wavefront или разбиения по строкам с передачей граничных данных.

- **2ж (OpenMP)**  
  - Антизависимость WAR.  
  - D = (2, −3), d = (<, >).  
  - Решение: копия входного массива → полная параллелизация.

- **3з (OpenMP)**  
  - Оба цикла независимы по данным.  
  - Полностью параллелятся через `collapse(2)`.
